Glossary — every term used on this page, one line each
AI Portfolio
The system's own recommended allocation (Judge -> Risk Engine -> Portfolio Construction) -- a target, not what you actually hold.
Allocation
What fraction of the total portfolio value one asset (or cash) represents, as a percentage.
Backfilled vs. live
Backfilled = a simulated decision from a historical replay, used to build up a track record fast. Live = a decision made in real time, right now.
Brier score
Whether stated confidence was honest -- did "90% confident" calls come true ~90% of the time? Lower is better; 0 is perfect, ~0.25 is a coin flip.
Confidence
How sure the system is about a decision, 0 (a guess) to 1 (certain).
Deflated Sharpe Ratio
The Sharpe ratio, corrected for the chance that trying many variations makes a result look good by luck alone, not skill.
Expected alpha
The extra return a decision is expected to earn beyond just holding the market -- can be negative.
Fill method
The order-execution assumption used to estimate realistic trading costs for a position.
Hit rate
Of resolved decisions, the fraction that called the right direction. 1.0 = always right, 0.5 = a coin flip.
Mark-to-mid
The paper return if a position could be closed right now at the current market price, before fees.
My Portfolio
What you actually hold, entered by hand as real transactions -- ground truth, the only input Portfolio Construction uses for current_allocation.
Net of costs
The same return, after subtracting realistic trading fees and price-impact -- the more honest number.
NOT_IMPLEMENTED
A deliberate decision (cost, an access relationship not pursued, or genuine infeasibility) -- never a broken or failing source.
Regime
The market condition (e.g. risk-on/risk-off) the system read at the moment it made a decision.
Resolved / unresolved
Resolved = the outcome is known (hit target, hit stop, or timed out). Unresolved = still waiting -- every decision has a multi-week horizon.
Risk score
How much a decision could lose if wrong, 0 (very safe) to 1 (very risky) -- feeds directly into how large a position it's sized at.
Sharpe ratio
Return earned relative to how bumpy/inconsistent the returns were. Higher means steadier, more dependable gains.
UNAVAILABLE
Investigated and found to be genuinely blocked (e.g. a bot-challenge or DNS failure) -- a real, attempted access failure.

My Portfolio

What you actually hold, entered by hand as real transactions — the only input Portfolio Construction uses for current_allocation. Append-only and transactional (Phase 5b): every BUY/SELL you record for an asset sums with every prior one for that asset into the position shown below; nothing you enter ever overwrites or deletes a prior entry. Enter CASH for uninvested cash (a stated USD amount, always an absolute total, not summed like a real asset). The symbol field isn't limited to the autocomplete list above it — typing a real token not yet tracked here (e.g. ADA, LTC) is checked against CoinGecko and, if it's a genuine listed coin, added as a newly tracked asset automatically; a symbol that isn't real is rejected.
